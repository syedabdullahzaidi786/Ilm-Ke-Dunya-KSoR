The Ilm Ke Dunya mobile app is being built as a lightweight, user-friendly
experience for Islamic learning and daily spiritual reference.

The app is designed to make key content accessible on mobile, where many users
prefer quick reading, searching, and repeated daily engagement.

## Planned experience

- Quick access to Quran, Duas, Hadith, and core references
- Clean mobile-first reading experience
- Fast search for everyday learning and revisit patterns
- A practical companion to the wider web and API surfaces

## Current status

The mobile app is currently in the upcoming phase and will be launched soon.
